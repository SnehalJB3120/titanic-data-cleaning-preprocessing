# titanic-data-cleaning-preprocessing
Titanic data cleaning and preprocessing project using Python, Pandas, and NumPy.

## Project Overview
This project performs data cleaning and preprocessing on the Titanic dataset using Python, Pandas, and NumPy. The dataset was cleaned by handling missing values, removing duplicate records, encoding categorical variables, detecting and treating outliers, and normalizing numerical features.

## Dataset
- Titanic Dataset (train.csv and test.csv)

## Tools Used
- Python
- Pandas
- NumPy

## Preprocessing Steps
- Missing Value Treatment
- Duplicate Removal
- Feature Encoding
- Outlier Detection and Treatment
- Feature Normalization
